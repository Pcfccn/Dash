### Фото 1–4 — SNIFF (широковещательные кадры, мотор заглушён)
48–62 fps, IDS 43–45, редкие CAN LOST. Заметные кадры:
- `0F1` b0: `99 A5 …` — 4-байтовый, младший байт «дышит» (счётчик/контрольная)
- `0BE`, `0C9`, `1E1` — 4-байтовые, значения FF/FD/FE (насыщенные — счётчики, не датчики)
- `1AA`, `1BA`, `191` — 8–9-байтовые массивы вида `65 64 67 68 61 5F 5E 5A 59`
  и `B3 B2 B1 B0 B4 AF AE AD` — похоже на мультиплексированный набор близких
  значений (кандидаты на массив датчиков/температур, но при заглушённом моторе
  малоинформативны — нужен прогретый прогон)

| Oil pressure | `0x1470` | ❌ **вероятный источник NRC 22/31** (requestOutOfRange) — DID не поддержан этим E98 |
| DPF regen status | `0x20F6` | ? Inactive — не отличить ответ от дефолта, нужен прогон при активной регенерации |
| EGT / EGR T° | `0x78`/`0x6B` + пробы | ❌ «no reply yet» — этот ECM не отвечает; искать EGT-DID |

**NRC 22/31** = сервис 0x22, код 0x31 `requestOutOfRange` → один из mode-22 DID
не поддержан. Раз soot/oil-temp/∆p отвечают, а oil-pressure на DIAG показывает
дефолтный `00=0.00`, скорее всего отвергается именно **oil pressure `0x1470`**.

## КРИТИЧНО: скорость/обороты/rail/batt/load не читались

Пользователь подтвердил на заведённом моторе: `RPM`, `KM/H`, `BOOST`, `RAIL`,
`BATT`, `LOAD` вообще не появляются. Причина найдена: читались **только те
mode-01 группы, чей ответ влезает в один CAN-кадр**. `temps={05,5C,0F}` влезает
(oil 0x5C не поддержан → ответ короткий) и читается. А `fast={0C,0D,04,0B}` (10
байт) и `misc={23,42,33,01}` (14 байт) требуют многокадрового ISO-TP (FF + Flow
Control + CF), который на этом E98 при опросе через блокирующий flush дисплея не
доезжает.

**Фикс:** группы разбиты так, что каждый ответ — один кадр:
`fastA={0C,0D}`, `fastB={04,0B,33}`, `misc={23,42}`, `mil={01}`; планировщик
расширен с 8 до 10 шагов, `fastA` опрашивается дважды за цикл. Одиночные кадры на
этом ECM доказанно доходят всегда — значит все базовые датчики теперь появятся.

## Выводы / что дальше
1. ✅ Исправлен `0x3039`: 0xFFFF → NaN (`--`), а не «65535 км».
2. Подтверждены рабочими: oil temp `0x1154`, soot `0x336A`, ∆p `0x20F4`
   (плюс ранее ATF `0x1940`, селектор `0x1F5`).
3. `0x1470` (oil pressure) — почти наверняка не тот DID для E98. Нужен
   альтернативный DID либо снять пробу при заведённом моторе.
4. EGT / EGR T° — стандартные PID молчат; следующий кандидат — enhanced-DID
   EGT из семейства Global-B, либо массивы `1AA`/`191` из SNIFF на прогретом
   прогоне.
5. Всё ключевое (∆p, oil pressure, regen, EGT) требует **прогона с заведённым
   двигателем** — текущий тест KOEO подтвердил только «холодные» параметры.
